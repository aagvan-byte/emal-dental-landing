# Эмаль - лендинг стоматологии

Одностраничный сайт стоматологической клиники. Демо-проект для портфолио, клиника вымышленная.

## Что внутри

- Первый экран с главным предложением, преимуществами и цифрами
- Услуги с ценами, блок об оборудовании, этапы первого визита
- Отзывы и частые вопросы (раскрывающийся список)
- Форма записи с проверкой полей и защитой от спам-ботов
- Адаптивная вёрстка для телефона, планшета и компьютера
- Оптимизированные изображения (WebP, разные размеры под экран)
- Lighthouse: 99-100 по скорости, 100 по доступности, SEO и лучшим практикам

## Стек

[Astro](https://astro.build) · [Tailwind CSS](https://tailwindcss.com) · деплой на [Vercel](https://vercel.com)

## Запуск

```sh
npm install
npm run dev     # http://localhost:4321
npm run build   # сборка в папку dist/
```

## Как адаптировать под клиента

Все тексты, цены, отзывы и вопросы лежат в `src/data/site.ts`, фото - в `src/assets/`, цвета и шрифты - в `src/styles/global.css`.
